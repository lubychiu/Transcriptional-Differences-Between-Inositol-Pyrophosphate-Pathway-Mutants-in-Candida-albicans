# Transcriptional-Differences-Between-Inositol-Pyrophosphate-Pathway-Mutants-in-Candida-albicans
This project contains a fully integrated RNA-seq differential gene expression (DGE) and Gene Ontology (GO) enrichment analysis pipeline tailored for the diploid fungal pathogen Candida albicans. The workflow investigates how mutations disrupting the inositol pyrophosphate signaling pathway (dbl, kcs1, and vip1) alter global transcriptional profiles relative to a Wild Type (WT) benchmark.

For full pipeline, refer to PIPELINE.md.
